# Delta Table Operation — INSERT

## 1. Brief Description

- INSERT is used to add new rows into an existing Delta table.
- The most common append pattern in PySpark is `DataFrameWriter.mode("append")`.
- Spark SQL supports inserting rows using `INSERT INTO`.
- `INSERT INTO ... VALUES` inserts explicitly specified rows.
- `INSERT INTO ... SELECT` inserts rows returned by a query.
- `INSERT OVERWRITE` replaces existing data in the target table or target partitions rather than simply appending rows.
- `DataFrameWriterV2.append()` provides a table-oriented PySpark API for appending rows.
- `MERGE INTO` can insert rows conditionally, but it is an upsert operation rather than a simple INSERT.
- For a normal append, Delta writes new Parquet file(s) and records `ADD` actions in the Delta transaction log.
- INSERT does not perform row-level matching; if the same business key already exists, another row can be appended unless additional logic prevents it.
- The incoming DataFrame/query schema must be compatible with the target table schema, unless schema evolution is explicitly enabled where supported.

# 2. Syntax

## 2.1 PySpark — DataFrame API

### Append rows to an existing Delta table

```python
df.write \
    .format("delta") \
    .mode("append") \
    .saveAsTable("table_name")
```

### Append to a Delta table by path

```python
df.write \
    .format("delta") \
    .mode("append") \
    .save("table_path")
```

### Append using DataFrameWriterV2

```python
df.writeTo("table_name") \
    .using("delta") \
    .append()
```

### Append with schema evolution

```python
df.write \
    .format("delta") \
    .mode("append") \
    .option("mergeSchema", "true") \
    .saveAsTable("table_name")
```

## 2.2 Spark SQL

### INSERT INTO — VALUES

```sql
INSERT INTO table_name
VALUES
    (value_1, value_2, ...),
    (value_1, value_2, ...);
```

### INSERT INTO — SELECT

```sql
INSERT INTO table_name
SELECT
    column_1,
    column_2,
    ...
FROM source_table;
```

### INSERT INTO — SELECT with explicit target columns

```sql
INSERT INTO table_name
    (column_1, column_2, ...)
SELECT
    source_column_1,
    source_column_2,
    ...
FROM source_table;
```

### INSERT OVERWRITE

```sql
INSERT OVERWRITE TABLE table_name
SELECT
    column_1,
    column_2,
    ...
FROM source_table;
```

### INSERT OVERWRITE with VALUES

```sql
INSERT OVERWRITE TABLE table_name
VALUES
    (value_1, value_2, ...),
    (value_1, value_2, ...);
```

# 3. Example

## 3.1 PySpark — DataFrame API

Assume the existing Delta table is:

```text
employees

+---+------+----------+------+
| id|  name|department|salary|
+---+------+----------+------+
|  1|  John|        IT|100000|
|  2| Alice|        HR| 90000|
+---+------+----------+------+
```

Create a DataFrame containing new employees:

```python
new_employees = spark.createDataFrame(
    [
        (3, "Bob", "IT", 95000),
        (4, "David", "Finance", 85000)
    ],
    ["id", "name", "department", "salary"]
)
```

Append the new rows:

```python
new_employees.write \
    .format("delta") \
    .mode("append") \
    .saveAsTable("employees")
```

Result:

```text
+---+------+----------+------+
| id|  name|department|salary|
+---+------+----------+------+
|  1|  John|        IT|100000|
|  2| Alice|        HR| 90000|
|  3|   Bob|        IT| 95000|
|  4| David|   Finance| 85000|
+---+------+----------+------+
```

### Important

```python
.mode("append")
```

means: keep the existing rows and add the incoming DataFrame rows.

## 3.2 Spark SQL

### INSERT INTO ... VALUES

```sql
INSERT INTO employees
VALUES
    (3, 'Bob', 'IT', 95000),
    (4, 'David', 'Finance', 85000);
```

### INSERT INTO ... SELECT

```sql
INSERT INTO employees
SELECT
    id,
    name,
    department,
    salary
FROM new_employees;
```

# 4. Code Variants for Specific Scenarios

## 4.1 Insert a single row

```sql
INSERT INTO employees
VALUES
    (5, 'Emma', 'HR', 92000);
```

## 4.2 Insert multiple rows

```sql
INSERT INTO employees
VALUES
    (5, 'Emma', 'HR', 92000),
    (6, 'James', 'IT', 105000),
    (7, 'Sophia', 'Finance', 88000);
```

## 4.3 Insert selected columns

```sql
INSERT INTO employees
    (id, name, department)
VALUES
    (8, 'Olivia', 'HR');
```

The omitted column must be nullable or have an applicable default/generated value.

## 4.4 Insert from another table

```sql
INSERT INTO employees
SELECT
    id,
    name,
    department,
    salary
FROM employee_staging;
```

## 4.5 Insert with transformation

```sql
INSERT INTO employees
SELECT
    id,
    upper(name),
    department,
    salary * 1.10
FROM employee_staging;
```

## 4.6 Insert with a filter

```sql
INSERT INTO employees
SELECT
    id,
    name,
    department,
    salary
FROM employee_staging
WHERE department = 'IT';
```

## 4.7 Insert using a DataFrame transformation

```python
new_employees = (
    source_df
    .filter("department = 'IT'")
    .select("id", "name", "department", "salary")
)

new_employees.write \
    .format("delta") \
    .mode("append") \
    .saveAsTable("employees")
```

## 4.8 Insert using DataFrameWriterV2

```python
new_employees.writeTo("employees") \
    .using("delta") \
    .append()
```

## 4.9 Insert with schema evolution

```python
new_employees.write \
    .format("delta") \
    .option("mergeSchema", "true") \
    .mode("append") \
    .saveAsTable("employees")
```

Session-level automatic schema evolution where applicable:

```python
spark.conf.set(
    "spark.databricks.delta.schema.autoMerge.enabled",
    "true"
)
```

## 4.10 Insert into a partitioned table

```sql
INSERT INTO employees
VALUES
    (9, 'Noah', 'IT', 97000);
```

If the table is partitioned by `department`, Spark routes the row to the corresponding partition.

# 5. INSERT OVERWRITE Variants

`INSERT OVERWRITE` has replacement semantics. It should not be confused with normal append/insert.

## 5.1 Overwrite the table

```sql
INSERT OVERWRITE TABLE employees
SELECT
    id,
    name,
    department,
    salary
FROM employee_source;
```

## 5.2 Overwrite using VALUES

```sql
INSERT OVERWRITE TABLE employees
VALUES
    (1, 'John', 'IT', 110000),
    (2, 'Alice', 'HR', 95000);
```

## 5.3 Partition overwrite

```sql
INSERT OVERWRITE TABLE employees
PARTITION (department = 'IT')
SELECT
    id,
    name,
    salary
FROM it_employee_source;
```

# 6. Dynamic Partition Overwrite

For partitioned tables, dynamic partition overwrite can replace only partitions represented by the incoming data.

```python
spark.conf.set(
    "spark.sql.sources.partitionOverwriteMode",
    "dynamic"
)

df.write \
    .format("delta") \
    .mode("overwrite") \
    .insertInto("employees")
```

# 7. INSERT vs APPEND vs OVERWRITE vs MERGE

| Operation | Main Purpose | Existing Rows | Matching Logic |
|---|---|---|---|
| `INSERT INTO` | Add rows | Preserved | No |
| `df.write.mode("append")` | Add DataFrame rows | Preserved | No |
| `writeTo(...).append()` | Add DataFrame rows | Preserved | No |
| `INSERT OVERWRITE` | Replace data | Replaced according to overwrite scope | No |
| `MERGE INTO` | Upsert/conditional modification | Can update/insert/delete | Yes |

# 8. INSERT vs MERGE

A normal INSERT does not check whether a key already exists.

```sql
INSERT INTO employees
VALUES
    (1, 'John', 'IT', 120000);
```

If `id = 1` already exists, another row with `id = 1` can be inserted.

For conditional update-or-insert behavior, use `MERGE`:

```sql
MERGE INTO employees AS target
USING employee_updates AS source
ON target.id = source.id

WHEN MATCHED THEN
    UPDATE SET *

WHEN NOT MATCHED THEN
    INSERT *;
```

# 9. What Happens Internally in Delta

For a normal append:

```python
new_employees.write \
    .format("delta") \
    .mode("append") \
    .saveAsTable("employees")
```

Conceptually:

```text
Incoming DataFrame
        |
        v
Spark writes new Parquet file(s)
        |
        v
Delta transaction
        |
        +---- ADD file-003.parquet
        +---- ADD file-004.parquet
        |
        v
New Delta table version
```

The existing Parquet files remain part of the table.

# 10. Important Syntax Patterns to Remember

## PySpark — Most Common

```python
df.write \
    .format("delta") \
    .mode("append") \
    .saveAsTable("table_name")
```

## PySpark — DataFrameWriterV2

```python
df.writeTo("table_name") \
    .using("delta") \
    .append()
```

## Spark SQL — VALUES

```sql
INSERT INTO table_name
VALUES (...);
```

## Spark SQL — SELECT

```sql
INSERT INTO table_name
SELECT ...
FROM source_table;
```

## Spark SQL — Explicit Target Columns

```sql
INSERT INTO table_name
    (column_1, column_2)
SELECT
    source_column_1,
    source_column_2
FROM source_table;
```

## Spark SQL — Overwrite

```sql
INSERT OVERWRITE TABLE table_name
SELECT ...
FROM source_table;
```

## Spark SQL — Upsert

```sql
MERGE INTO target
USING source
ON merge_condition
WHEN MATCHED THEN UPDATE SET *
WHEN NOT MATCHED THEN INSERT *;
```

# 11. Interview Cheat Sheet

### How do you insert a DataFrame into an existing Delta table?

```python
df.write \
    .format("delta") \
    .mode("append") \
    .saveAsTable("employees")
```

### How do you insert rows using Spark SQL?

```sql
INSERT INTO employees
VALUES
    (3, 'Bob', 'IT', 95000);
```

### How do you insert data from another table?

```sql
INSERT INTO employees
SELECT *
FROM employee_staging;
```

### What is the difference between append and overwrite?

```text
append
  -> existing data remains
  -> incoming data is added

overwrite
  -> existing data in the overwrite scope is replaced
  -> incoming data becomes the replacement
```

### Does INSERT check for duplicate keys?

```text
No.

INSERT is not an upsert operation.
```

Use `MERGE INTO` when matching logic is required.

### What happens to the Delta transaction log during an append?

```text
New Parquet file(s)
       |
       v
ADD actions in _delta_log
       |
       v
New Delta table version
```

# 12. Quick Reference

| Scenario | Recommended Syntax |
|---|---|
| Append DataFrame to Delta table | `df.write.format("delta").mode("append").saveAsTable(...)` |
| Append with DataFrameWriterV2 | `df.writeTo(...).using("delta").append()` |
| Insert literal rows | `INSERT INTO ... VALUES` |
| Insert query results | `INSERT INTO ... SELECT` |
| Insert selected target columns | `INSERT INTO table (cols...) SELECT ...` |
| Replace table data | `INSERT OVERWRITE` |
| Replace selected partitions | Partition overwrite |
| Update existing + insert new | `MERGE INTO` |
| Evolve schema while appending | `mergeSchema = true` |

# 13. Key Mental Model

```text
                    DELTA INSERT
                         |
          +--------------+--------------+
          |                             |
     Simple Append                 Conditional
          |                             |
   +------+-------+                   MERGE
   |              |
INSERT INTO   DataFrame append
   |              |
VALUES / SELECT   df.write.mode("append")
   |
   v
New rows added
   |
   v
New Parquet file(s)
   |
   v
ADD actions in _delta_log
   |
   v
New Delta table version
```

The most important distinction is:

```text
INSERT / APPEND
    = add rows

INSERT OVERWRITE
    = replace data in the overwrite scope

MERGE
    = conditionally UPDATE / INSERT / DELETE
```
